# Cyber

Τερματικό **SSH** και **τοπικό κέλυφος** για **Android, Windows και Linux**, στο πνεύμα του Termux, με διεπαφή που ρυθμίζεται μέχρι την παραμικρή λεπτομέρεια: θέματα, καθένα από τα 16 χρώματα, γραμματοσειρά, δρομέας, γραμμή πλήκτρων, γρήγορες εντολές… Οι τρεις εκδόσεις μοιράζονται την ίδια διεπαφή και την ίδια μορφή αντιγράφου ασφαλείας: οι ρυθμίσεις και οι διακομιστές σου περνούν από το κινητό στον υπολογιστή με ένα μόνο αρχείο.

Σχεδιασμένο για το Galaxy Z Fold: όταν είναι κλειστό, οι συνδέσεις ανοίγουν σε ένα συρτάρι· όταν είναι ανοιχτό (ή στον υπολογιστή), μένουν ορατές στα αριστερά.

Όλες οι εκδόσεις βρίσκονται στην καρτέλα [*Releases*](https://github.com/apk-fold/Cyber/releases), μαζί με τα αθροίσματα SHA-256. Μεταγλωττίζονται αυτόματα από το GitHub Actions σε κάθε αλλαγή του κώδικα.

- **Android**: άνοιξε το `Cyber.apk`, επίτρεψε την εγκατάσταση από αυτή την πηγή και πάτησε *Εγκατάσταση*. Οι ενημερώσεις εγκαθίστανται πάνω από την προηγούμενη έκδοση χωρίς να χάνονται οι ρυθμίσεις (ίδιο κλειδί υπογραφής).
- **Windows**: τα αρχεία δεν είναι υπογεγραμμένα, οπότε το SmartScreen θα ζητήσει *Περισσότερες πληροφορίες → Εκτέλεση ούτως ή άλλως*.

## Τι κάνει το Cyber

### Τερματικό
- Μηχανή [xterm.js](https://xtermjs.org): 256 χρώματα και χρώμα 24 bit, Unicode, σύνδεσμοι με δυνατότητα κλικ, απόδοση μέσω GPU.
- Απεριόριστες **καρτέλες** (μετονομασία, αντιγραφή, επανασύνδεση, αντιγραφή όλου του κειμένου), **αναζήτηση** στο ιστορικό, ιστορικό έως 100.000 γραμμές.
- Αντιγραφή/επικόλληση με δεξί κλικ, με την επιλογή ή με Ctrl+C / Ctrl+V (κατ' επιλογή).

### Τοπικό κέλυφος
- **Android**: το κέλυφος του συστήματος (`/system/bin/sh`) σε **πραγματικό ψευδοτερματικό** (εγγενής μονάδα), με **σενάριο εκκίνησης** που επεξεργάζεσαι στις ρυθμίσεις (προτροπή, ψευδώνυμα, μεταβλητές).
- **Windows**: PowerShell από προεπιλογή, ή `cmd.exe`, `pwsh`, `wsl.exe`…
- **Linux**: το κέλυφός σου (`$SHELL`).
- Ρυθμιζόμενη εντολή, ορίσματα και φάκελος εκκίνησης.

### SSH
- Αποθηκευμένα **προφίλ** (όνομα, κεντρικός υπολογιστής, θύρα, χρήστης, χρώμα, ξεχωριστό θέμα ανά διακομιστή) και **γρήγορη σύνδεση** με `χρήστης@host:θύρα`.
- Κωδικός πρόσβασης (ζητείται κάθε φορά ή απομνημονεύεται) ή **κλειδί SSH**: δημιουργία κλειδιών **Ed25519** μέσα στην εφαρμογή (το δημόσιο κλειδί αντιγράφεται με ένα άγγιγμα), εισαγωγή κλειδιών OpenSSH, PEM και PuTTY, φράσεις πρόσβασης.
- **Επαλήθευση του αποτυπώματος** του διακομιστή στην πρώτη σύνδεση και προειδοποίηση αν αλλάξει.
- Keep-alive, ρυθμιζόμενο χρονικό όριο, **εντολή κατά την εκκίνηση** (π.χ. `tmux attach || tmux`).
- Στο Android, μια ειδοποίηση κρατά τις συνεδρίες ανοιχτές όταν η εφαρμογή περνά στο παρασκήνιο.

### Προσαρμογή
- **12 θέματα**: Cyber Neon, Μεσάνυχτα, Νύχτα στο Τόκιο, Dracula, Nord, One Dark, Gruvbox, Monokai, Solarized, Matrix, Ρετρό κεχριμπαρένιο, Χαρτί (ανοιχτό).
- **Επεξεργαστής χρωμάτων**: φόντο, κείμενο, δρομέας, επιλογή και τα 16 χρώματα ANSI, με ζωντανή προεπισκόπηση· εξαγωγή και εισαγωγή θεμάτων.
- Χρώμα έμφασης της διεπαφής, περιθώρια, καρτέλες πάνω ή κάτω.
- Γραμματοσειρά: ενσωματωμένες JetBrains Mono και Fira Code, ή οποιαδήποτε εγκατεστημένη· μέγεθος, διάστιχο, απόσταση χαρακτήρων, βάρη, ελάχιστη αντίθεση.
- Δρομέας μπλοκ, υπογράμμιση ή γραμμή, που αναβοσβήνει ή όχι· κουδούνι ως αναλαμπή, ήχος ή δόνηση.

### Πληκτρολόγιο αφής
- **Γραμμή πλήκτρων** τύπου Termux (ESC, TAB, CTRL, ALT, βέλη, HOME, END, PG↑/PG↓, F1–F12…) της οποίας τη διάταξη γράφεις μόνος σου, σε 1 έως 4 σειρές. Οποιοδήποτε άλλο πλήκτρο στέλνει το κείμενό του (`|`, `~`, `:wq`…).
- «Κολλημένα» CTRL και ALT: ένα πάτημα = μία φορά, δύο γρήγορα πατήματα = κλείδωμα.
- **Ζουμ με δύο δάχτυλα** στο τερματικό, δόνηση στο πάτημα (απενεργοποιείται).

### Γρήγορες εντολές
Το κουμπί ⚡ στέλνει μια αποθηκευμένη εντολή στην ενεργή καρτέλα, με ή χωρίς Enter.

### Αντίγραφο ασφαλείας
Εξαγωγή σε JSON όλων των ρυθμίσεων, θεμάτων, συνδέσεων και αξιόπιστων διακομιστών (κωδικοί και ιδιωτικά κλειδιά μόνο αν το ζητήσεις) και επαναφορά σε άλλη συσκευή.

## Μεταγλώττιση από εσένα

Χρειάζεσαι [Node.js](https://nodejs.org) 22.

```sh
npm install
npm start              # εκκινεί την έκδοση υπολογιστή σε λειτουργία ανάπτυξης
npm run dist:win       # πρόγραμμα εγκατάστασης + φορητή έκδοση Windows → release/
npm run dist:linux     # AppImage + tar.gz → release/ (εκτέλεση σε Linux)
```

Για το APK (JDK 21 και Android SDK, ή Android Studio):

```sh
npm install
npm run build:web      # αντιγράφει τη διεπαφή στο android/app/src/main/assets/www
cd android
gradlew assembleRelease   # → android/app/build/outputs/apk/release/app-release.apk
```

Η εγγενής μονάδα του τοπικού κελύφους (`android/app/src/main/cpp`) μεταγλωττίζεται με το NDK, το οποίο εγκαθιστά το Android Studio όταν χρειάζεται.

## Υπογραφή του APK

Όλες οι εκδόσεις υπογράφονται με **το ίδιο κλειδί** (`signing/cyber.jks`) ώστε οι ενημερώσεις να εγκαθίστανται πάνω από την προηγούμενη. Αυτό το κλειδί είναι δημόσιο στο αποθετήριο: εγκατάστησε το Cyber μόνο από αυτό το αποθετήριο. Για ιδιωτικό κλειδί, πρόσθεσε στο *Settings › Secrets › Actions* τα secrets `CYBER_KEYSTORE_B64` (το αρχείο .jks σε base64), `CYBER_KEYSTORE_PASSWORD`, `CYBER_KEY_ALIAS` και `CYBER_KEY_PASSWORD` (η αλλαγή κλειδιού απαιτεί απεγκατάσταση της παλιάς έκδοσης: κάνε πρώτα εξαγωγή του αντιγράφου ασφαλείας).

## Καλό να ξέρεις

- Οι ρυθμίσεις, οι συνδέσεις, τα κλειδιά και οι αξιόπιστοι διακομιστές αποθηκεύονται **μόνο στη συσκευή**, χωρίς επιπλέον κρυπτογράφηση. Μην αποθηκεύεις κωδικούς σε κοινόχρηστη συσκευή.
- Το τοπικό κέλυφος του Android δίνει πρόσβαση στις εντολές του συστήματος (`ls`, `cat`, `ping`, `top`…), όχι σε πλήρες Linux με διαχειριστή πακέτων όπως το Termux: γι' αυτό, συνδέσου μέσω SSH σε έναν διακομιστή (ή στο ίδιο το Termux με `sshd`).

## Οργάνωση του αποθετηρίου

| Φάκελος | Περιεχόμενο |
|---|---|
| `web/` | Κοινή διεπαφή (HTML, CSS, JavaScript) |
| `desktop/` | Έκδοση Windows και Linux (Electron, ssh2, node-pty) |
| `android/` | Έκδοση Android (WebView, JSch, ψευδοτερματικό σε C) |
| `scripts/` | Προετοιμασία διεπαφής και βοηθήματα μεταγλώττισης |
| `tests/` | Πραγματικές δοκιμές SSH, τοπικού κελύφους και διεπαφής (εκτελούνται σε κάθε μεταγλώττιση) |
| `signing/` | Κλειδί υπογραφής του APK |
