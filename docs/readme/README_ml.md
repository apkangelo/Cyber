# Cyber

**Android, Windows, Linux** എന്നിവയ്ക്കുള്ള **SSH** ടെർമിനലും **ലോക്കൽ ഷെല്ലും**. Termux-ന്റെ ശൈലിയിൽ, ഏറ്റവും ചെറിയ വിശദാംശം വരെ ക്രമീകരിക്കാവുന്ന ഇന്റർഫേസോടെ: തീമുകൾ, 16 നിറങ്ങളിൽ ഓരോന്നും, ഫോണ്ട്, കഴ്‌സർ, കീ ബാർ, ദ്രുത കമാൻഡുകൾ… മൂന്ന് പതിപ്പുകളും ഒരേ ഇന്റർഫേസും ഒരേ ബാക്കപ്പ് ഫോർമാറ്റും പങ്കിടുന്നു: നിങ്ങളുടെ ക്രമീകരണങ്ങളും സെർവറുകളും ഒരൊറ്റ ഫയലിലൂടെ ഫോണിൽ നിന്ന് PC-യിലേക്ക് മാറ്റാം.

Galaxy Z Fold-നായി രൂപകൽപ്പന ചെയ്തത്: മടക്കിയിരിക്കുമ്പോൾ കണക്ഷനുകൾ ഒരു ഡ്രോയറിൽ തുറക്കും; തുറന്നിരിക്കുമ്പോൾ (അല്ലെങ്കിൽ PC-യിൽ) അവ ഇടതുവശത്ത് എപ്പോഴും കാണാം.

## ഡൗൺലോഡ്

| സിസ്റ്റം | ഫയൽ | |
|---|---|---|
| Android | **[Cyber.apk](https://github.com/apk-fold/Cyber/releases/latest/download/Cyber.apk)** | Android 8 അല്ലെങ്കിൽ പുതിയത് |
| Windows | **[Cyber-Setup.exe](https://github.com/apk-fold/Cyber/releases/latest/download/Cyber-Setup.exe)** | ഇൻസ്റ്റാളർ |
| Windows | [Cyber-Portable.exe](https://github.com/apk-fold/Cyber/releases/latest/download/Cyber-Portable.exe) | ഇൻസ്റ്റാൾ ചെയ്യേണ്ടതില്ല |
| Linux | **[Cyber.AppImage](https://github.com/apk-fold/Cyber/releases/latest/download/Cyber.AppImage)** | `chmod +x Cyber.AppImage` തുടർന്ന് പ്രവർത്തിപ്പിക്കുക |
| Linux | [Cyber-linux.tar.gz](https://github.com/apk-fold/Cyber/releases/latest/download/Cyber-linux.tar.gz) | എക്‌സ്‌ട്രാക്റ്റ് ചെയ്ത് `./cyber` പ്രവർത്തിപ്പിക്കുക |

എല്ലാ പതിപ്പുകളും SHA-256 ഹാഷുകളോടൊപ്പം [*Releases*](https://github.com/apk-fold/Cyber/releases) ടാബിലുണ്ട്. കോഡിൽ ഓരോ മാറ്റം വരുമ്പോഴും GitHub Actions അവ സ്വയമേവ ബിൽഡ് ചെയ്യുന്നു.

- **Android**: `Cyber.apk` തുറന്ന്, ഈ ഉറവിടത്തിൽ നിന്നുള്ള ഇൻസ്റ്റാളേഷൻ അനുവദിച്ച്, *ഇൻസ്റ്റാൾ ചെയ്യുക* ടാപ്പ് ചെയ്യുക. അപ്‌ഡേറ്റുകൾ ക്രമീകരണങ്ങൾ നഷ്ടപ്പെടാതെ പഴയ പതിപ്പിന് മുകളിൽ ഇൻസ്റ്റാൾ ആകും (ഒരേ സൈനിംഗ് കീ).
- **Windows**: ഫയലുകൾ സൈൻ ചെയ്തിട്ടില്ല, അതിനാൽ SmartScreen *More info → Run anyway* തിരഞ്ഞെടുക്കാൻ ആവശ്യപ്പെടും.

## Cyber എന്തൊക്കെ ചെയ്യുന്നു

### ടെർമിനൽ
- [xterm.js](https://xtermjs.org) എഞ്ചിൻ: 256 നിറങ്ങളും 24-ബിറ്റ് നിറവും, Unicode, ക്ലിക്ക് ചെയ്യാവുന്ന ലിങ്കുകൾ, GPU റെൻഡറിംഗ്.
- പരിധിയില്ലാത്ത **ടാബുകൾ** (പേരുമാറ്റുക, ഡ്യൂപ്ലിക്കേറ്റ് ചെയ്യുക, വീണ്ടും കണക്റ്റ് ചെയ്യുക, മുഴുവൻ ടെക്‌സ്റ്റും പകർത്തുക), ചരിത്രത്തിൽ **തിരയൽ**, 100,000 വരികൾ വരെ ക്രമീകരിക്കാവുന്ന ചരിത്രം.
- റൈറ്റ് ക്ലിക്ക്, തിരഞ്ഞെടുക്കുമ്പോൾ, അല്ലെങ്കിൽ Ctrl+C / Ctrl+V വഴി കോപ്പി/പേസ്റ്റ് (നിങ്ങളുടെ ഇഷ്ടം).

### ലോക്കൽ ഷെൽ
- **Android**: സിസ്റ്റം ഷെൽ (`/system/bin/sh`) ഒരു **യഥാർത്ഥ സ്യൂഡോ-ടെർമിനലിൽ** (നേറ്റീവ് മൊഡ്യൂൾ), ക്രമീകരണങ്ങളിൽ എഡിറ്റ് ചെയ്യാവുന്ന **സ്റ്റാർട്ടപ്പ് സ്ക്രിപ്റ്റോടെ** (പ്രോംപ്റ്റ്, അലിയാസുകൾ, വേരിയബിളുകൾ).
- **Windows**: സ്ഥിരസ്ഥിതിയായി PowerShell, അല്ലെങ്കിൽ `cmd.exe`, `pwsh`, `wsl.exe`…
- **Linux**: നിങ്ങളുടെ ഷെൽ (`$SHELL`).
- കമാൻഡ്, ആർഗ്യുമെന്റുകൾ, ആരംഭ ഫോൾഡർ എന്നിവ ക്രമീകരിക്കാം.

### SSH
- സേവ് ചെയ്ത **പ്രൊഫൈലുകൾ** (പേര്, ഹോസ്റ്റ്, പോർട്ട്, ഉപയോക്താവ്, നിറം, ഓരോ സെർവറിനും സ്വന്തം തീം) കൂടാതെ `ഉപയോക്താവ്@ഹോസ്റ്റ്:പോർട്ട്` വഴി **ദ്രുത കണക്ഷൻ**.
- പാസ്‌വേഡ് (ഓരോ തവണയും ചോദിക്കുകയോ ഓർമ്മിക്കുകയോ) അല്ലെങ്കിൽ **SSH കീ**: ആപ്പിനുള്ളിൽ **Ed25519** കീ നിർമ്മാണം (പബ്ലിക് കീ ഒറ്റ ടാപ്പിൽ പകർത്താം), OpenSSH, PEM, PuTTY കീകൾ ഇമ്പോർട്ട് ചെയ്യൽ, പാസ്‌ഫ്രേസുകൾ.
- ആദ്യ കണക്ഷനിൽ സെർവറിന്റെ **ഫിംഗർപ്രിന്റ് പരിശോധന**, അത് മാറിയാൽ മുന്നറിയിപ്പ്.
- Keep-alive, ക്രമീകരിക്കാവുന്ന ടൈംഔട്ട്, **തുടക്കത്തിലെ കമാൻഡ്** (ഉദാ. `tmux attach || tmux`).
- Android-ൽ, ആപ്പ് പശ്ചാത്തലത്തിലേക്ക് പോകുമ്പോൾ ഒരു അറിയിപ്പ് സെഷനുകൾ തുറന്നുവെക്കുന്നു.

### വ്യക്തിഗതമാക്കൽ
- **12 തീമുകൾ**: Cyber Neon, Midnight, Tokyo Night, Dracula, Nord, One Dark, Gruvbox, Monokai, Solarized, Matrix, Retro Amber, Paper (ലൈറ്റ്).
- **കളർ എഡിറ്റർ**: പശ്ചാത്തലം, ടെക്‌സ്റ്റ്, കഴ്‌സർ, തിരഞ്ഞെടുപ്പ്, 16 ANSI നിറങ്ങൾ എന്നിവ ലൈവ് പ്രിവ്യൂവോടെ; തീമുകൾ എക്‌സ്‌പോർട്ടും ഇമ്പോർട്ടും ചെയ്യാം.
- ഇന്റർഫേസിന്റെ ആക്‌സന്റ് നിറം, മാർജിൻ, ടാബുകൾ മുകളിലോ താഴെയോ.
- ഫോണ്ട്: JetBrains Mono, Fira Code എന്നിവ ഉൾപ്പെടുത്തിയിട്ടുണ്ട്, അല്ലെങ്കിൽ ഇൻസ്റ്റാൾ ചെയ്ത ഏത് ഫോണ്ടും; വലുപ്പം, വരി ഉയരം, അക്ഷര അകലം, കനം, കുറഞ്ഞ കോൺട്രാസ്റ്റ്.
- ബ്ലോക്ക്, അടിവര, അല്ലെങ്കിൽ ബാർ കഴ്‌സർ, മിന്നുന്നതോ അല്ലാത്തതോ; ബെൽ ഫ്ലാഷ്, ശബ്ദം, അല്ലെങ്കിൽ വൈബ്രേഷൻ ആയി.

### ടച്ച് കീബോർഡ്
- Termux ശൈലിയിലുള്ള **കീ ബാർ** (ESC, TAB, CTRL, ALT, അമ്പടയാളങ്ങൾ, HOME, END, PG↑/PG↓, F1–F12…), അതിന്റെ ലേഔട്ട് നിങ്ങൾ തന്നെ എഴുതുന്നു, 1 മുതൽ 4 വരി വരെ. മറ്റേതൊരു കീയും അതിന്റെ ടെക്‌സ്റ്റ് അയയ്ക്കുന്നു (`|`, `~`, `:wq`…).
- "സ്റ്റിക്കി" CTRL, ALT: ഒരു ടാപ്പ് = ഒരു തവണ, രണ്ട് വേഗ ടാപ്പുകൾ = ലോക്ക്.
- ടെർമിനലിൽ **രണ്ട് വിരൽ സൂം**, കീ അമർത്തുമ്പോൾ വൈബ്രേഷൻ (ഓഫ് ചെയ്യാം).

### ദ്രുത കമാൻഡുകൾ
⚡ ബട്ടൺ സേവ് ചെയ്ത ഒരു കമാൻഡ് സജീവ ടാബിലേക്ക് Enter-ഓടെയോ അല്ലാതെയോ അയയ്ക്കുന്നു.

### ബാക്കപ്പ്
എല്ലാ ക്രമീകരണങ്ങളും തീമുകളും കണക്ഷനുകളും വിശ്വസനീയ സെർവറുകളും JSON ആയി എക്‌സ്‌പോർട്ട് ചെയ്യാം (പാസ്‌വേഡുകളും പ്രൈവറ്റ് കീകളും നിങ്ങൾ ആവശ്യപ്പെട്ടാൽ മാത്രം), തുടർന്ന് മറ്റൊരു ഉപകരണത്തിൽ പുനഃസ്ഥാപിക്കാം.

## സ്വയം ബിൽഡ് ചെയ്യാൻ

[Node.js](https://nodejs.org) 22 ആവശ്യമാണ്.

```sh
npm install
npm start              # PC പതിപ്പ് ഡെവലപ്‌മെന്റ് മോഡിൽ പ്രവർത്തിപ്പിക്കുന്നു
npm run dist:win       # Windows ഇൻസ്റ്റാളർ + പോർട്ടബിൾ പതിപ്പ് → release/
npm run dist:linux     # AppImage + tar.gz → release/ (Linux-ൽ പ്രവർത്തിപ്പിക്കുക)
```

APK-ക്കായി (JDK 21, Android SDK, അല്ലെങ്കിൽ Android Studio):

```sh
npm install
npm run build:web      # ഇന്റർഫേസ് android/app/src/main/assets/www-ലേക്ക് പകർത്തുന്നു
cd android
gradlew assembleRelease   # → android/app/build/outputs/apk/release/app-release.apk
```

ലോക്കൽ ഷെല്ലിന്റെ നേറ്റീവ് മൊഡ്യൂൾ (`android/app/src/main/cpp`) NDK ഉപയോഗിച്ച് കംപൈൽ ചെയ്യുന്നു; ആവശ്യമെങ്കിൽ Android Studio അത് ഇൻസ്റ്റാൾ ചെയ്യും.

## APK സൈനിംഗ്

അപ്‌ഡേറ്റുകൾ പഴയ പതിപ്പിന് മുകളിൽ ഇൻസ്റ്റാൾ ആകാനായി എല്ലാ പതിപ്പുകളും **ഒരേ കീ** (`signing/cyber.jks`) ഉപയോഗിച്ച് സൈൻ ചെയ്തിരിക്കുന്നു. ഈ കീ റിപ്പോസിറ്ററിയിൽ പരസ്യമാണ്: Cyber ഈ റിപ്പോസിറ്ററിയിൽ നിന്ന് മാത്രം ഇൻസ്റ്റാൾ ചെയ്യുക. ഒരു സ്വകാര്യ കീ ഉപയോഗിക്കാൻ, *Settings › Secrets › Actions*-ൽ `CYBER_KEYSTORE_B64` (base64-ലുള്ള .jks ഫയൽ), `CYBER_KEYSTORE_PASSWORD`, `CYBER_KEY_ALIAS`, `CYBER_KEY_PASSWORD` എന്നീ secrets ചേർക്കുക (കീ മാറ്റിയാൽ പഴയ പതിപ്പ് അൺഇൻസ്റ്റാൾ ചെയ്യേണ്ടിവരും: ആദ്യം നിങ്ങളുടെ ബാക്കപ്പ് എക്‌സ്‌പോർട്ട് ചെയ്യുക).

## അറിഞ്ഞിരിക്കേണ്ടവ

- ക്രമീകരണങ്ങൾ, കണക്ഷനുകൾ, കീകൾ, വിശ്വസനീയ സെർവറുകൾ എന്നിവ അധിക എൻക്രിപ്ഷൻ ഇല്ലാതെ **ഉപകരണത്തിൽ മാത്രം** സൂക്ഷിക്കുന്നു. പങ്കിട്ട ഉപകരണത്തിൽ പാസ്‌വേഡ് സേവ് ചെയ്യരുത്.
- Android-ന്റെ ലോക്കൽ ഷെൽ സിസ്റ്റം കമാൻഡുകളിലേക്ക് (`ls`, `cat`, `ping`, `top`…) ആക്‌സസ് നൽകുന്നു, Termux പോലെ പാക്കേജ് മാനേജറുള്ള പൂർണ്ണ Linux അല്ല: അതിനായി SSH വഴി ഒരു സെർവറിലേക്ക് (അല്ലെങ്കിൽ `sshd` ഉപയോഗിച്ച് Termux-ലേക്ക് തന്നെ) കണക്റ്റ് ചെയ്യുക.

## റിപ്പോസിറ്ററിയുടെ ഘടന

| ഫോൾഡർ | ഉള്ളടക്കം |
|---|---|
| `web/` | പൊതു ഇന്റർഫേസ് (HTML, CSS, JavaScript) |
| `desktop/` | Windows, Linux പതിപ്പ് (Electron, ssh2, node-pty) |
| `android/` | Android പതിപ്പ് (WebView, JSch, C-യിൽ എഴുതിയ സ്യൂഡോ-ടെർമിനൽ) |
| `scripts/` | ഇന്റർഫേസ് തയ്യാറാക്കലും ബിൽഡ് സഹായികളും |
| `tests/` | യഥാർത്ഥ SSH, ലോക്കൽ ഷെൽ, ഇന്റർഫേസ് ടെസ്റ്റുകൾ (ഓരോ ബിൽഡിലും പ്രവർത്തിക്കുന്നു) |
| `signing/` | APK സൈനിംഗ് കീ |
