# Cyber

**SSH**-терминал и **локальная оболочка** для **Android, Windows и Linux** в духе Termux, с интерфейсом, который настраивается до мелочей: темы, каждый из 16 цветов, шрифт, курсор, панель клавиш, быстрые команды… Все три версии используют один и тот же интерфейс и один формат резервной копии: настройки и серверы переносятся с телефона на ПК одним файлом.

Создан для Galaxy Z Fold: в сложенном виде подключения открываются в выдвижной панели; в разложенном (или на ПК) они всегда видны слева.

## Скачать

| Система | Файл | |
|---|---|---|
| Android | **[Cyber.apk](https://github.com/apk-fold/Cyber/releases/latest/download/Cyber.apk)** | Android 8 или новее |
| Windows | **[Cyber-Setup.exe](https://github.com/apk-fold/Cyber/releases/latest/download/Cyber-Setup.exe)** | установщик |

| Linux | **[Cyber.AppImage](https://github.com/apk-fold/Cyber/releases/latest/download/Cyber.AppImage)** | `chmod +x Cyber.AppImage`, затем запустить |
| Linux | [Cyber-linux.tar.gz](https://github.com/apk-fold/Cyber/releases/latest/download/Cyber-linux.tar.gz) | распаковать и запустить `./cyber` |

Все версии лежат на вкладке [*Releases*](https://github.com/apk-fold/Cyber/releases) вместе с контрольными суммами SHA-256. Они автоматически собираются через GitHub Actions при каждом изменении кода.

- **Android**: открой `Cyber.apk`, разреши установку из этого источника и нажми *Установить*. Обновления устанавливаются поверх, без потери настроек (тот же ключ подписи).
- **Windows**: файлы не подписаны, поэтому SmartScreen попросит выбрать *Подробнее → Выполнить в любом случае*.

## Что умеет Cyber

### Терминал
- Движок [xterm.js](https://xtermjs.org): 256 цветов и 24-битный цвет, Unicode, кликабельные ссылки, отрисовка на GPU.
- Неограниченное число **вкладок** (переименовать, дублировать, переподключить, скопировать весь текст), **поиск** по истории, размер истории до 100 000 строк.
- Копирование и вставка правой кнопкой мыши, по выделению или через Ctrl+C / Ctrl+V (на выбор).

### Локальная оболочка
- **Android**: системная оболочка (`/system/bin/sh`) в **настоящем псевдотерминале** (нативный модуль) со **стартовым скриптом**, который редактируется в настройках (приглашение, алиасы, переменные).
- **Windows**: по умолчанию PowerShell, либо `cmd.exe`, `pwsh`, `wsl.exe`…
- **Linux**: твоя оболочка (`$SHELL`).
- Настраиваемые команда, аргументы и стартовая папка.

### SSH
- Сохранённые **профили** (имя, хост, порт, пользователь, цвет, своя тема для каждого сервера) и **быстрое подключение** `пользователь@хост:порт`.
- Пароль (запрашивается каждый раз или запоминается) или **SSH-ключ**: генерация ключей **Ed25519** прямо в приложении (публичный ключ копируется одним касанием), импорт ключей OpenSSH, PEM и PuTTY, парольные фразы.
- **Проверка отпечатка** сервера при первом подключении и предупреждение, если он изменился.
- Keep-alive, настраиваемый тайм-аут, **команда при запуске** (например, `tmux attach || tmux`).
- На Android уведомление удерживает сессии открытыми, когда приложение уходит в фон.

### Оформление
- **12 тем**: Кибер-неон, Полночь, Ночной Токио, Dracula, Nord, One Dark, Gruvbox, Monokai, Solarized, Матрица, Ретро-янтарь, Бумага (светлая).
- **Редактор цветов**: фон, текст, курсор, выделение и 16 цветов ANSI с живым предпросмотром; экспорт и импорт тем.
- Акцентный цвет интерфейса, отступы, вкладки сверху или снизу.
- Шрифт: встроенные JetBrains Mono и Fira Code или любой установленный шрифт; размер, межстрочный интервал, межбуквенный интервал, начертания, минимальный контраст.
- Курсор блоком, подчёркиванием или чертой, мигающий или нет; звонок вспышкой, звуком или вибрацией.

### Сенсорная клавиатура
- **Панель клавиш** в стиле Termux (ESC, TAB, CTRL, ALT, стрелки, HOME, END, PG↑/PG↓, F1–F12…), раскладку которой ты задаёшь сам, от 1 до 4 рядов. Любая другая клавиша отправляет свой текст (`|`, `~`, `:wq`…).
- «Залипающие» CTRL и ALT: одно касание — один раз, два быстрых касания — фиксация.
- **Масштабирование двумя пальцами** в терминале, вибрация при нажатии (отключается).

### Быстрые команды
Кнопка ⚡ отправляет сохранённую команду в активную вкладку, с нажатием Enter или без.

### Резервная копия
Экспорт в JSON всех настроек, тем, подключений и доверенных серверов (пароли и закрытые ключи — только по твоему запросу) и восстановление на другом устройстве.

## Сочетания клавиш (ПК)

| Сочетание | Действие |
|---|---|
| Ctrl+Shift+T | Новая локальная оболочка |
| Ctrl+Shift+N | Новое SSH-подключение |
| Ctrl+Shift+W | Закрыть вкладку |
| Ctrl+Tab / Ctrl+Shift+Tab | Следующая / предыдущая вкладка |
| Alt+1 … Alt+9 | Перейти на вкладку n |
| Ctrl+Shift+C / Ctrl+Shift+V | Копировать / вставить |
| Ctrl+Shift+F | Поиск |
| Ctrl + / Ctrl − / Ctrl 0 | Размер текста |
| Ctrl+, | Настройки |

## Собрать самому

Нужен [Node.js](https://nodejs.org) 22.

```sh
npm install
npm start              # запускает версию для ПК в режиме разработки
npm run dist:win       # установщик + портативная версия для Windows → release/
npm run dist:linux     # AppImage + tar.gz → release/ (запускать под Linux)
```

Для APK (JDK 21 и Android SDK или Android Studio):

```sh
npm install
npm run build:web      # копирует интерфейс в android/app/src/main/assets/www
cd android
gradlew assembleRelease   # → android/app/build/outputs/apk/release/app-release.apk
```

Нативный модуль локальной оболочки (`android/app/src/main/cpp`) компилируется с помощью NDK, который Android Studio устанавливает при необходимости.

## Подпись APK

Все версии подписаны **одним и тем же ключом** (`signing/cyber.jks`), чтобы обновления устанавливались поверх. Этот ключ открыто лежит в репозитории: устанавливай Cyber только из этого репозитория. Чтобы использовать закрытый ключ, добавь в *Settings › Secrets › Actions* секреты `CYBER_KEYSTORE_B64` (файл .jks в base64), `CYBER_KEYSTORE_PASSWORD`, `CYBER_KEY_ALIAS` и `CYBER_KEY_PASSWORD` (смена ключа требует удалить старую версию: сначала экспортируй резервную копию).

## Полезно знать

- Настройки, подключения, ключи и доверенные серверы хранятся **только на устройстве**, без дополнительного шифрования. Не сохраняй пароли на общем устройстве.
- Локальная оболочка Android даёт доступ к системным командам (`ls`, `cat`, `ping`, `top`…), а не к полноценному Linux с менеджером пакетов, как Termux: для этого подключись по SSH к серверу (или к самому Termux через `sshd`).

## Структура репозитория

| Папка | Содержимое |
|---|---|
| `web/` | Общий интерфейс (HTML, CSS, JavaScript) |
| `desktop/` | Версия для Windows и Linux (Electron, ssh2, node-pty) |
| `android/` | Версия для Android (WebView, JSch, псевдотерминал на C) |
| `scripts/` | Подготовка интерфейса и вспомогательные скрипты сборки |
| `tests/` | Реальные тесты SSH, локальной оболочки и интерфейса (запускаются при каждой сборке) |
| `signing/` | Ключ подписи APK |
