# Cyber

**SSH**-термінал і **локальна оболонка** для **Android, Windows і Linux** у дусі Termux, з інтерфейсом, який налаштовується до найдрібніших деталей: теми, кожен із 16 кольорів, шрифт, курсор, панель клавіш, швидкі команди… Усі три версії мають однаковий інтерфейс і однаковий формат резервної копії: налаштування й сервери переходять із телефона на ПК одним файлом.

Створено для Galaxy Z Fold: у складеному стані підключення відкриваються у висувній панелі; у розкладеному (або на ПК) вони завжди видимі ліворуч.

## Завантажити

| Система | Файл | |

| Linux | **[Cyber.AppImage](https://github.com/apk-fold/Cyber/releases/latest/download/Cyber.AppImage)** | `chmod +x Cyber.AppImage`, потім запустити |
| Linux | [Cyber-linux.tar.gz](https://github.com/apk-fold/Cyber/releases/latest/download/Cyber-linux.tar.gz) | розпакувати й запустити `./cyber` |

Усі версії є на вкладці [*Releases*](https://github.com/apk-fold/Cyber/releases) разом із контрольними сумами SHA-256. GitHub Actions автоматично збирає їх після кожної зміни коду.

- **Android**: відкрий `Cyber.apk`, дозволь встановлення з цього джерела й натисни *Установити*. Оновлення встановлюються поверх без втрати налаштувань (той самий ключ підпису).
- **Windows**: файли не підписані, тож SmartScreen попросить вибрати *Докладніше → Усе одно запустити*.

## Що вміє Cyber

### Термінал
- Рушій [xterm.js](https://xtermjs.org): 256 кольорів і 24-бітний колір, Unicode, клікабельні посилання, рендеринг на GPU.
- Необмежена кількість **вкладок** (перейменувати, дублювати, перепідключити, скопіювати весь текст), **пошук** в історії, розмір історії до 100 000 рядків.
- Копіювання й вставлення правою кнопкою миші, за виділенням або через Ctrl+C / Ctrl+V (на вибір).

### Локальна оболонка
- **Android**: системна оболонка (`/system/bin/sh`) у **справжньому псевдотерміналі** (нативний модуль) зі **стартовим скриптом**, який редагується в налаштуваннях (запрошення, аліаси, змінні).
- **Windows**: за замовчуванням PowerShell, або `cmd.exe`, `pwsh`, `wsl.exe`…
- **Linux**: твоя оболонка (`$SHELL`).
- Налаштовувані команда, аргументи й стартова тека.

### SSH
- Збережені **профілі** (назва, хост, порт, користувач, колір, окрема тема для кожного сервера) і **швидке підключення** `користувач@хост:порт`.
- Пароль (запитується щоразу або запам'ятовується) чи **SSH-ключ**: генерація ключів **Ed25519** прямо в застосунку (публічний ключ копіюється одним дотиком), імпорт ключів OpenSSH, PEM і PuTTY, парольні фрази.
- **Перевірка відбитка** сервера під час першого підключення й попередження, якщо він змінився.
- Keep-alive, налаштовуваний тайм-аут, **команда під час запуску** (наприклад, `tmux attach || tmux`).
- На Android сповіщення тримає сесії відкритими, коли застосунок переходить у фон.

### Персоналізація
- **12 тем**: Кібер-неон, Північ, Нічний Токіо, Dracula, Nord, One Dark, Gruvbox, Monokai, Solarized, Матриця, Ретро-бурштин, Папір (світла).
- **Редактор кольорів**: фон, текст, курсор, виділення й 16 кольорів ANSI з живим попереднім переглядом; експорт та імпорт тем.
- Акцентний колір інтерфейсу, відступи, вкладки згори чи знизу.
- Шрифт: вбудовані JetBrains Mono і Fira Code або будь-який встановлений шрифт; розмір, міжрядковий інтервал, міжлітерний інтервал, накреслення, мінімальний контраст.
- Курсор блоком, підкресленням або рискою, блимаючий чи ні; дзвінок спалахом, звуком або вібрацією.

### Сенсорна клавіатура
- **Панель клавіш** у стилі Termux (ESC, TAB, CTRL, ALT, стрілки, HOME, END, PG↑/PG↓, F1–F12…), розкладку якої ти пишеш сам, від 1 до 4 рядів. Будь-яка інша клавіша надсилає свій текст (`|`, `~`, `:wq`…).
- «Липкі» CTRL і ALT: один дотик — один раз, два швидкі дотики — фіксація.
- **Масштабування двома пальцями** в терміналі, вібрація під час натискання (вимикається).

### Швидкі команди
Кнопка ⚡ надсилає збережену команду в активну вкладку, з Enter або без.

### Резервна копія
Експорт у JSON усіх налаштувань, тем, підключень і довірених серверів (паролі та приватні ключі — лише якщо ти попросиш) і відновлення на іншому пристрої.

## Зібрати самостійно

Потрібен [Node.js](https://nodejs.org) 22.

```sh
npm install
npm start              # запускає версію для ПК у режимі розробки
npm run dist:win       # інсталятор + портативна версія для Windows → release/
npm run dist:linux     # AppImage + tar.gz → release/ (запускати під Linux)
```

Для APK (JDK 21 і Android SDK або Android Studio):

```sh
npm install
npm run build:web      # копіює інтерфейс у android/app/src/main/assets/www
cd android
gradlew assembleRelease   # → android/app/build/outputs/apk/release/app-release.apk
```

Нативний модуль локальної оболонки (`android/app/src/main/cpp`) компілюється за допомогою NDK, який Android Studio встановлює за потреби.

## Підпис APK

Усі версії підписані **одним і тим самим ключем** (`signing/cyber.jks`), щоб оновлення встановлювалися поверх. Цей ключ відкрито лежить у репозиторії: встановлюй Cyber лише з цього репозиторію. Щоб використати приватний ключ, додай у *Settings › Secrets › Actions* секрети `CYBER_KEYSTORE_B64` (файл .jks у base64), `CYBER_KEYSTORE_PASSWORD`, `CYBER_KEY_ALIAS` і `CYBER_KEY_PASSWORD` (зміна ключа вимагає видалити стару версію: спершу експортуй резервну копію).

## Варто знати

- Налаштування, підключення, ключі й довірені сервери зберігаються **лише на пристрої**, без додаткового шифрування. Не зберігай паролі на спільному пристрої.
- Локальна оболонка Android дає доступ до системних команд (`ls`, `cat`, `ping`, `top`…), а не до повноцінного Linux із менеджером пакетів, як Termux: для цього підключися по SSH до сервера (або до самого Termux через `sshd`).

## Структура репозиторію

| Тека | Вміст |
|---|---|
| `web/` | Спільний інтерфейс (HTML, CSS, JavaScript) |
| `desktop/` | Версія для Windows і Linux (Electron, ssh2, node-pty) |
| `android/` | Версія для Android (WebView, JSch, псевдотермінал на C) |
| `scripts/` | Підготовка інтерфейсу й допоміжні скрипти збирання |
| `tests/` | Реальні тести SSH, локальної оболонки та інтерфейсу (запускаються під час кожного збирання) |
| `signing/` | Ключ підпису APK |
